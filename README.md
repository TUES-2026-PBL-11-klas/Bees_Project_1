# Bees_Project_1
CleverCookin е интуитивна платформа, която оптимизира готвенето чрез алгоритъм за намиране на рецепти според наличните в дома продукти. Системата автоматизира планирането на менюто, като помага на потребителите да спестяват средства и ефективно да намаляват разхищението на храна.


How to build it:
docker compose up -d --build

How to run migrations:
docker compose exec backend alembic upgrade head

How to trigger GitHub Actions:
Actions -> Run
